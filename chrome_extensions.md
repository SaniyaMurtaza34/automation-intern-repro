# Chrome Extensions Setup

## Extensions Installed and Why

I set up Google Chrome and explored a few useful browser extensions that can make web development and testing easier.

- **React Developer Tools:** This extension helps me inspect React components, understand component structures, and check their props and state. It is useful when testing React applications and investigating UI-related issues.

- **Redux DevTools:** I use this extension to monitor and debug application state. It helps me understand how the state changes when I interact with different parts of an application.

- **JSON Viewer:** This extension makes JSON responses easier to read by formatting them into a structured and organised view. It is particularly helpful when working with APIs and checking response data during testing.

- **Lighthouse:** This tool helps evaluate web application performance, accessibility, SEO, and best practices. It gives useful insights into areas that could be improved.

## What Was the Most Useful Thing I Learned?

The most useful thing I learned was how these browser extensions can make debugging and testing more efficient. As a QA Engineer, I usually focus on identifying issues from a user's perspective. However, exploring these tools helped me understand what happens behind the scenes, especially how React components work, how application state changes, and how API responses are structured. I also learned that Lighthouse can help identify performance and accessibility issues that might affect the overall user experience. 

Overall, this setup has given me a better understanding of browser-based debugging and will help me investigate issues more effectively during testing.
