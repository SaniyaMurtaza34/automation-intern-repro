# My Terminal Setup and Learning Experience

### 1. Which terminal client did you choose? Why?

I chose 'Windows Terminal with PowerShell' because I use Windows and wanted to become more comfortable working with the command line. It provides a simple and user-friendly interface and allows me to run commands, navigate folders, manage files and work with Git without always relying on a graphical interface.

### 2. What customizations (if any) did you make?

I kept the setup simple for now and used the default PowerShell environment. I focused more on understanding basic terminal commands and getting comfortable with the interface rather than spending too much time on themes or plugins.

### 3. What was the most useful command you learned today?

The most useful command I learned was "cd" (Change Directory). It allows me to move between folders directly from the terminal.

I also practised some other useful commands:

- `pwd` – Displays the current working directory.
- `ls` – Lists files and folders.
- `mkdir` – Creates a new directory.
- `clear` – Clears the terminal screen.
- `git status` – Shows the current Git working-tree status.
- `git add .` – Stages changes for a commit.
- `git commit -m "message"` – Saves changes with a descriptive commit message.
- `git push` – Pushes committed changes to GitHub.

### My Reflection

This activity helped me understand how useful the terminal can be in everyday development and QA work. Before this, I mostly relied on graphical interfaces to manage files and projects. Now I have a better understanding of how to navigate directories, execute commands and use Git through the terminal.

I realised that learning basic terminal commands can save time and make development and testing workflows more efficient. I would like to continue practising these commands and become more confident using the command line in my daily work.
