# My Experience with AI Coding Assistants

## 1. AI Tools I Tried

As part of this task, I explored and experimented with two AI coding assistants to understand how they can support software development and improve productivity.

**1. ChatGPT**

I used ChatGPT to generate code examples, troubleshoot coding issues, and understand programming concepts that were new to me. I also used it to break down complex technical topics into simpler explanations. One thing I liked was being able to ask follow-up questions and request alternative solutions when something wasn't clear.

**2. Claude AI**

I also experimented with Claude AI as another coding assistant. I used it to generate code snippets, explain programming concepts, review code, and explore different approaches to solving development problems. I found its detailed explanations and structured responses helpful, especially when I wanted to understand the reasoning behind a particular solution.

## 2. What Worked Well?

Overall, I found all two AI tools useful, although each offered a slightly different experience.

- **ChatGPT:** I found it helpful for debugging, understanding errors, generating examples, and learning unfamiliar concepts through interactive conversations.
- **Claude AI:** I liked its detailed explanations, code analysis, and ability to suggest alternative approaches to solving problems.

Another benefit was that these tools helped me approach problems from different perspectives. Instead of spending too much time trying to understand an issue independently, I could use AI to explore possible solutions and learn from the explanations.

## 3. What Didn't Work Well?

Although AI coding assistants are useful, I also noticed some limitations.

- Sometimes, AI-generated code was not completely accurate or needed modifications before it could work correctly.
- ChatGPT and Claude sometimes provided solutions that were more complicated than necessary.
- AI-generated explanations are not always guaranteed to be correct, so I still needed to verify the information and test the suggested code.

This helped me understand that AI should not replace problem-solving skills or critical thinking. Developers still need to understand the code they are using rather than blindly accepting AI-generated suggestions.

## 4. When Is AI Most Useful for Coding?

In my opinion, AI is most useful when:

- Generating basic code snippets and repetitive functions.
- Identifying potential bugs and suggesting debugging approaches.
- Explaining unfamiliar programming concepts.
- Reviewing code and suggesting improvements.
- Exploring alternative solutions to technical problems.
- Learning new programming languages, frameworks, and development tools.

As someone working in Software Quality Assurance and learning automation testing with Playwright and TypeScript, I can also see significant value in using AI to generate test scripts, explain automation errors, suggest test scenarios, and improve test coverage.

## 5. My Overall Experience

My experience with GitHub Copilot, ChatGPT, and Claude AI was positive. I realised that each tool has its own strengths, and using them together can make learning and development more efficient.

What I found most valuable was not simply getting code generated, but understanding why a particular solution works and how I could improve it.

I believe AI will play an increasingly important role in software development and quality engineering. However, developers still need strong technical knowledge, logical thinking, and the ability to review and validate AI-generated output.

For me, AI is best used as a development assistant and learning partner, rather than something that does all the thinking for me.
