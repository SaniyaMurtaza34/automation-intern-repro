# Git Knowledge - Learning Reflection

### 1. Have you used Git before? If so, in what context?

Yes, I have some previous experience using Git for software development and testing projects. I have used it to manage code changes, work with GitHub repositories, and keep track of project updates. I understand the basic concepts of repositories, commits, and pushing changes, but I am still improving my knowledge of Git commands and version control workflows.

### 2. Which Git client (if any) did you choose? Why?

I decided to use Git through the integrated terminal in VS Code because it is convenient to manage my code and version control in one place. It allows me to run Git commands, track changes, commit updates, and push my work to GitHub without switching between different applications.

### 3. What was the most interesting thing you learned about Git today?

The most interesting thing I learned is how Git keeps track of changes over time and allows developers to go back to previous versions of their code when needed. I also learned how commits help maintain a clear history of changes and how pushing updates to GitHub makes it easier to share work and collaborate with others.

Overall, this activity helped me refresh my understanding of Git and become more comfortable with using version control in my daily development and QA workflow.
